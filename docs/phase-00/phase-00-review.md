## Design decisions and rationale

Deep navy anchors identity and primary actions; teal-tinted surfaces make educational content calm; orange is a restrained accent. White cards, consistent 18px corners and subtle borders provide hierarchy without dense LMS chrome. The hero uses an original SVG illustration of data exploration rather than stock AI imagery. Original PNG logos remain unchanged and on light backing, with iAnalyze primary and iTeam explicitly represented as parent.

Inter and Cairo are bundled locally with OFL notices for predictable offline typography. Language is data-driven through structured dictionaries, and a generated classic-script bundle supports direct file opening. Arabic layouts reverse the reading edge and directional arrows while code, numeric ratios, times, technical terms and logos remain correctly isolated. Arabic default is a **proposal**, not an approved project decision.

Organizer and Leader are separate previews. Assigned reviews and a restricted document boundary communicate Organizer scope; applications, roles, result approval, fixed-program activities and announcements belong to Leader planning. No actual private document content is present. The supplied Team Syllabus remains only at the explicitly provided Downloads path.

## Open the preview

Double-click `design-preview/index.html` in Chrome or Edge. No package installation, build, account or internet connection is needed. Use the top **Preview view / صفحة المعاينة** selector to change designs and **AR / EN** in the main header to switch language. Choose **Wireframes / المخططات الأولية** for all ten layout pairs. Activity & submission includes an interface-state selector. On narrow screens, the menu button reveals public navigation.

Alternatively, from the repository root:

```powershell
python -m http.server 4173 --bind 127.0.0.1 --directory design-preview
```

Open `http://127.0.0.1:4173/`. Use Ctrl+C to stop the server. The QA server used during this task is stopped at handoff. Do not serve Downloads or future private documents.

### Measured contrast

All 13 specified semantic pairs passed their measured thresholds in the final suite. Representative ratios: primary white/navy **8.37:1**, body/white **14.17:1**, muted/canvas **5.42:1**, dark text/teal **4.53:1**, dark text/orange **5.31:1**, success **6.39:1**, warning **7.26:1**, error/white **7.65:1**, input boundary/white **3.70:1**. Inactive controls are also readable, although inactive component contrast has a WCAG exception. Official teal and orange are not used with white body text. Original logo colors are preserved.

### Verification limits

This is **not a WCAG conformance certification**. Screen-reader testing (NVDA/JAWS/VoiceOver), actual mobile hardware, touch gestures, Firefox/Safari, browser UI zoom, full keyboard task walkthroughs and human bilingual usability testing were not executed. Programmatic name/structure checks do not replace those audits. Contrast calculations cover listed semantic pairs, not every pixel. The CSS-width reflow proxy is not a claim of a browser zoom test. No backend, RLS, authentication, real file safety, registration delivery, grading or privacy enforcement test could run because those systems do not exist in Phase 00.
